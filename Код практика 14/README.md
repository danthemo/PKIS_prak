# Toir.Concurrency

Учебный проект для практической работы №14 по системе ТОиР. Проект демонстрирует управление транзакционно критичными операциями, конкурентным доступом и целостностью данных без подключения реальной базы данных.

## Что реализовано

- In-memory-хранилище с атомарными критичными секциями через `SemaphoreSlim`.
- Оптимистическая блокировка через поле `Version`.
- Идемпотентность операций назначения инженера и закрытия наряда через `operationId`.
- Сервисы для заявок, нарядов, запчастей, аудита и записей идемпотентности.
- Конкурентные xUnit-тесты, которые запускают параллельные `Task` через `Task.WhenAll`.
- SQL-примеры для PostgreSQL-подобной реализации в `sql/transaction_examples.sql`.

## Команды

```powershell
dotnet restore
dotnet build
dotnet test
```

## Структура

- `src/Toir.Concurrency` - доменные модели, DTO, сервисы и in-memory storage.
- `tests/Toir.Concurrency.Tests` - модульные и конкурентные тесты.
- `sql/transaction_examples.sql` - примеры SQL для optimistic locking, условного резерва, idempotency upsert и диагностики блокировок.

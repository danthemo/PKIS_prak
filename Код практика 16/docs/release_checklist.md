# Release checklist

## Контрольный список

- [ ] Версия обновлена.
- [ ] `CHANGELOG.md` заполнен.
- [ ] OpenAPI обновлен.
- [ ] Миграции проверены.
- [ ] Unit-тесты прошли.
- [ ] Integration-тесты прошли.
- [ ] Контрактная проверка прошла.
- [ ] Секреты не попали в репозиторий.
- [ ] Staging проверен.
- [ ] Smoke-тесты прошли.
- [ ] План отката указан.
- [ ] Метрики и алерты после выпуска проверены.

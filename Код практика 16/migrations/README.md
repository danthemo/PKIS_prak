# Миграции PostgreSQL

## Формат имени

Миграции именуются по формату:

```text
yyyyMMdd_NNN_description.sql
```

Пример:

```text
20260520_001_add_request_version.sql
```

Где `yyyyMMdd` — дата создания, `NNN` — порядковый номер за день, `description` — краткое описание на английском в `snake_case`.

## Порядок применения

1. Применять миграции строго по имени в лексикографическом порядке.
2. Перед применением на окружение проверить резервную копию или план восстановления.
3. На больших таблицах отдельно оценивать блокировки и время выполнения.
4. После применения проверить основные операции с заявками, нарядами, оборудованием и аудитом.

## Откат

Откат описывается для каждой миграции в release plan. Если миграция уже применена на production, файл миграции не редактируется. Компенсирующее изменение оформляется новой миграцией.

Миграции, удаляющие данные, требуют отдельного предупреждения, резервной копии и подтвержденного плана восстановления.

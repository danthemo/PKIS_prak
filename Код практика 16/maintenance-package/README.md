# Пакет сопровождения системы ТОиР

## Назначение

Пакет содержит эксплуатационные и проектные артефакты для сопровождения корпоративной системы технического обслуживания и ремонта. Он фиксирует правила изменения REST API `/api/v1`, миграций PostgreSQL, наблюдаемости, безопасности, выпуска версий и обработки инцидентов.

Материалы применяются вместе с клиент-серверным контуром ТОиР, где используются DTO-контракты, JWT/OIDC-аутентификация, трассировка через `traceId`, журнал аудита `audit_log`, миграции БД и CI/CD.

## Что входит в пакет

- версия API и контрактов фиксируется в OpenAPI;
- миграции БД описаны регламентом и SQL-файлами;
- наблюдаемость задается схемой логов, метриками и алертами;
- безопасность описывает работу с секретами, JWT-ключами и уязвимостями;
- тестирование и выпуск описаны через CI/CD pipeline и release checklist;
- управление инцидентами включает классификацию, порядок расследования и шаблон postmortem.

## Как использовать

1. Перед изменением API оформить запрос в `docs/api_change_request_template.md`.
2. При изменении контракта обновить `openapi/openapi-v1.yaml` в той же ветке.
3. При изменении схемы БД добавить новую миграцию в `migrations/` и пройти `docs/migration_checklist.md`.
4. Перед выпуском заполнить `CHANGELOG.md` и `docs/release_checklist.md`.
5. Для проверки базовых артефактов запустить скрипты из `scripts/`.

# Migration checklist

## Контрольный список

- [ ] Миграция имеет корректное имя.
- [ ] Миграция применена локально.
- [ ] Миграция применена на test.
- [ ] Проверено время выполнения.
- [ ] Проверены блокировки.
- [ ] Есть план отката.
- [ ] Проверены данные после применения.
- [ ] Документация обновлена.
- [ ] Проверена запись в `audit_log`.
- [ ] Проверены основные операции заявок и нарядов.

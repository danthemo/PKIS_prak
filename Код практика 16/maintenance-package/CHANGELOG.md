# Changelog

## v1.1.1

### Changed

- Уточнена обработка ошибок `VALIDATION_ERROR` для операций создания заявки и закрытия наряда.
- Ответы ошибок сохраняют `traceId` и машинно-читаемый код ошибки.

## v1.1.0

### Added

- Добавлена идемпотентность операций назначения инженера и закрытия наряда.
- Добавлены метрики `idempotency_replays_total` и `business_conflicts_total`.

## v1.0.0

### Added

- Базовый клиент-серверный контур системы ТОиР.
- REST API `/api/v1` для заявок, нарядов и оборудования.
- PostgreSQL-хранилище, DTO-контракты, JWT/OIDC-аутентификация и аудит операций.
